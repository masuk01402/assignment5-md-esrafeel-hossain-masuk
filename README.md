## Description of the project

This project is developed for Assignment 5 of the Basics of Programming course. The primary objective is to build the initial foundation for the FoCar project by setting up a Python application, importing necessary hardware and sensor libraries in `main.py`, and managing version control using Git and GitHub.

## User instruction

Microcontroller: Raspberry Pi Pico W.
Required Hardware Modules:
L298N Motor Driver
USB Cable Type B
Development Environment: Visual Studio Code (with Pico-W-Go extension)
Running the Project:
Open the project folder in your preferred IDE (Visual Studio Code).
Connect the Raspberry Pi Pico W to your computer via USB.
Open main.py and upload/run the script on the device.
